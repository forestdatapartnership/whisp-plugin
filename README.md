This is a QGIS plugin using the **Whisp API** to run deforestation risk analyses on your geometries right in QGIS. To install the plugin in your QGIS desktop software, please download the plugin by clicking the big green "**<> Code**" button at the top of this page and choosing "Download ZIP". Install it in QGIS through *"Manage and install Plugins..." --> "Install from ZIP"*.

For more information on Whisp, check the [OpenForis Whisp website](https://openforis.org/solutions/whisp/) and the [Whisp repository](https://github.com/forestdatapartnership/whisp).

For more information on Whisp API, check the [Whisp API website](https://whisp.openforis.org/) and the [Whisp API repository](https://github.com/forestdatapartnership/whisp-app).
